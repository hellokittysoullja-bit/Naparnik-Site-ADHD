# Скиллы проекта

Постоянная база знаний по дизайну для любого ИИ-сеанса в этом репозитории.
Грузятся автоматически, их не нужно каждый раз приносить руками.

Это **вендоренные копии чужих открытых репозиториев**, не наша работа.
Файлы скопированы дословно, без правок. Лицензии лежат в `LICENSES/`.

## Порядок применения

1. **`taste-skill`** первым: сначала «design read» (что за страница, для кого, каким языком),
   потом диалы, потом композиция. Заканчивать всегда Pre-Flight чек-листом из §14.
2. **`apple-design`** для всего, что двигается и на что нажимают: пружины, прерываемость,
   тач-таргеты, материалы, трекинг крупного текста.
3. **`emil-design-eng`** и **`animate`** когда дело дошло до конкретного компонента
   и конкретной анимации.

## Где они спорят с CLAUDE.md

`CLAUDE.md` в корне описывает уже принятые решения этого продукта и **имеет приоритет**,
когда речь о вещах, проверенных здесь на живых данных. Известные расхождения:

- **Иконки.** `taste-skill` §3.C не любит `lucide-react`. В проекте он уже стоит и используется
  везде. Правило скилла само разрешает исключение для существующей зависимости: менять
  библиотеку иконок целиком ради буквы скилла не надо.
- **Свои SVG.** `taste-skill` §4.8 запрещает рисовать декоративные SVG руками. Здесь кот,
  остров и спрайты построек нарисованы руками намеренно, это и есть бренд продукта,
  а не декоративная заглушка.
- **Коридор светлоты фона.** `CLAUDE.md` §3 фиксирует `oklch 0.152-0.172` во все часы суток.
  Замер подтверждает, что на этом коридоре держится весь контрастный бюджет. Любые советы
  скиллов про цвет фона подчиняются этому коридору.

## Обновление

```bash
git clone --depth 1 https://github.com/Leonxlnx/taste-skill.git
git clone --depth 1 https://github.com/emilkowalski/skills.git
```
Скопировать `SKILL.md` поверх, сверить `diff`, обновить число строк в таблице выше.
