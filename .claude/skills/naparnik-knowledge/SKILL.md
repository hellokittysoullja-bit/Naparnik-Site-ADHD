# Как работать

1. Прочитай `knowledge/INDEX.md` (одна страница) и `knowledge/decisions.md`.
2. Для каждого этапа, который трогаешь, открой его раздел в `knowledge/techniques.md` и пройди ВСЕ ID:
   взят / отброшен (почему) / не применим. Владельцу в ответе — короткий список ID взятых и отброшенных.
3. Силу доказательств бери из каталога, не из памяти. ✗ (опровергнуто) — никогда не приводить как довод.
4. Новое знание → строка в `techniques.md` (следующий номер в конце раздела), отчёт целиком → `research/NN-…/`.
   Решение владельца → `decisions.md` с датой. Ничего не удалять — только помечать.
5. Протокол целиком — `knowledge/README.md`.
