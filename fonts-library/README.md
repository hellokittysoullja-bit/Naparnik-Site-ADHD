# Библиотека шрифтов Напарника

Постоянное хранилище шрифтов проекта: каждый шрифт в своей папке — файлы, лицензия, образец, описание.
В сборку сайта не входит (сайт собирает свои шрифты в `public/fonts` через `design/fonts/build.py`).

| Папка | Шрифт | Лицензия |
|---|---|---|
| [`bionic-reading/`](bionic-reading/) | Bionic Reading (Fast-Font): жирные начала слов прямо в шрифте, кириллица | MIT |

Правило: только шрифты с лицензией, разрешающей наше использование. Платные и некоммерческие — нет.
