# Каталог приёмов «Напарника»

Одна строка — один приём. **ID не меняются никогда, строки не удаляются — только помечаются** (`~~…~~ → см. ID` или статус «—» с датой и причиной). Новое — в конец своего раздела, следующим номером. Дубли из разных источников слиты в одну строку.
**Сила:** ●●● мета-анализ или многократно воспроизведено · ●● эксперимент/РКИ или полевой A/B с данными · ● слова практика/кейс без данных · ○ гипотеза/вывод эксперта · ✗ не воспроизвелось/отозвано · ⚠ перенос на нас спорный (другая выборка, лаборатория, магазины приложений, США, вина перед другими) · [СДВГ] данные на СДВГ-выборке.
**Статус:** ✅ уже в коде (файл) · 📋 предложено/в плане · ⚑ ждёт решения владельца · — решено не использовать · 🚫 запрещено брендом.
**Источник:** `06 §A2` = research/06-…; `09/A`…`09/G` = research/09-ideal-onboarding/A…G (09/D — эксперт «Г», 09/E — критик, 09/G — проверка главного сеанса, 09/F — сводка); `10 §1.4` = research/10-youtube-study/SKILL.md; `yt <id> мм:сс` = видео (заметки — research/10-youtube-study/notes/<id>.md, остальные id — в отчётах 09); `dec` = knowledge/decisions.md. «(испр.)» — цифру/вывод поправили критик или проверка главного сеанса; в строке уже исправленный вариант.
