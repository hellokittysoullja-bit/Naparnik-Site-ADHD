## Правила работы (действуют всегда)
- **Процесс изменений:** короткие названия идей с источниками → владелец выбирает → скриншоты до/после → «да» → main.
- **Баги** — в main без вопроса, с тестом, который на старой сборке падает.
- **Push/merge в main** — только с явного разрешения каждый раз (CLAUDE.md §7).
- **Формат ответов:** структурированный текст в чате, НЕ артефакт («в следующий раз скинь… не артефактом, а просто текстом структурированным»).
- **Язык:** простой русский, визуальное доказательство (скриншоты), ничего не выдумывать; утверждения — только с научной или
  эмпирической опорой и пометкой силы.
- **Независимость:** не подстраиваться под владельца. Его ограничение («не больше 8») — потолок, не цель; если данные против — сказать.
- **Убеждение:** владелец хочет максимум («манипуляции» болью, желаниями, слабыми местами, персонализация). Граница — одна строкой,
  без лекций: без фальшивых таймеров, выдуманных цифр и отзывов, стыда и вины, тёмных паттернов (спрятанный крестик, скидка при уходе).
- **Каналы трафика:** только Instagram, Telegram, YouTube, Threads, TikTok. VK и Яндекс не предлагать. Юридических оговорок и
  «проверьте правила площадки» не писать («Ничего проверять не надо, я лучше знаю»).
- **Агенты:** владелец сам говорит, сколько нанимать; по умолчанию — один.

## Секреты
- `TELEGRAM_BOT_TOKEN` — только в Vercel (Secret). Никогда не просить в чате, не коммитить.
- Ключ YouTube Data API — только в scratchpad сеанса, никогда не печатать, не писать в репозиторий.
