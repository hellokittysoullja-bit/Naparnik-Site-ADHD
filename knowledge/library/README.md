# Библиотека приёмов, исследований и кейсов (с 10.11.2026)

Владелец: «записать все приёмы полностью и подробно, нейтрально, без привязки к продукту — чтобы любой агент понял,
что конкретно имелось в виду, и мог внедрить». Это **справочник мира**, а не план продукта. Привязка к Напарнику живёт
отдельно — в `knowledge/techniques.md` (короткие строки с ID и статусом). Здесь — полная версия знания.

## Правила
1. **Нейтрально.** Ни слова о Напарнике, коте, острове. Примеры внедрения — общие (лендинг, квиз, онбординг,
   пейвол, письмо, пуш, реклама, ролик, магазин).
2. **Подробно и однозначно.** Механизм — так, чтобы его нельзя было понять двумя способами. Оригинальное название
   (англ.) обязательно — по нему ищут первоисточник.
3. **Только проверенные цифры.** Каждая цифра — с источником. Не нашёл в источнике — «не проверено». Не выдумывать
   выборки, проценты, годы, цитаты.
4. **Внедряемость.** У каждой записи — конкретные шаги «как применить» и «как проверить» (метрика). Знание без
   применения сюда не пишется.
5. **Тёмные приёмы и манипуляции записываются тоже** — с механизмом, кейсами, последствиями (иски, штрафы, отток,
   репутация) и пометкой границы. Решение, применять ли, принимается в продукте по `decisions.md` и красным линиям.
6. **Ничего не удалять.** Опровергнутое — помечать «✗ опровергнуто/не воспроизвелось» с источником.

## Формат записи
```
### <код>. <Название по-русски> (<оригинальное название>)
- **Науки:** …
- **Кто открыл / описал, год; книга или статья:** …
- **Как работает (механизм):** 3–8 предложений.
- **Доказательства:** исследования — кто, год, выборка (N), условия, результат цифрами; мета-анализы; повторяемость.
- **Кейсы:** компания/кампания, год, что сделали, результат цифрами, источник. Кейс расписан подробно: контекст → ход → итог.
- **Как внедрить:** пошагово, где в воронке обычно используют, пример формулировки.
- **Как проверить:** метрика, A/B, на что смотреть.
- **Границы и риски:** когда не работает, обратный эффект, правовые случаи, этика.
- **Сила доказательств:** ●●● мета-анализ/повторено · ●● несколько исследований · ● одно исследование или кейс · ✗ опровергнуто.
- **Источники:** ссылки.
```
