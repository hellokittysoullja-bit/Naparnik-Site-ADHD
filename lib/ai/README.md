# Обвязка ИИ «Напарника» (`lib/ai`)

Единственный вход к модели во всём продукте: чат на Доме, голос кота в сессии, дробление задачи в Фокусе,
«Подскажи» в знакомстве, бот в Telegram. Прямой вызов модели вне `lib/ai` запрещён линтером
(`eslint.config.mjs`, правило `no-restricted-imports`).

Почему так устроено и откуда взят каждый приём — `research/20-ai-harness/proof.md` (таблица «Hermes / OpenAI
Agents SDK / Mastra → наш файл»). Разборы исходников — `research/20-ai-harness/*-analysis.md`.

## Слои

```
каналы       channels/web.ts          channels/telegram.ts         (+ app/api/*/route.ts — только транспорт)
               │ нормализуют вход, режут недоверенное, доставляют ответ в формате канала
агенты       agents/chat.ts   agents/session-voice.ts   agents/breakdown.ts
               │ что делать: правила задачи, лимиты, разбор ответа, заготовка
ядро         core/stream-turn.ts (поток)   harness.ts runTurn (разовый ответ)
               │ ход: проверка входа → middleware запроса → страхующие попытки → проверка выхода → итог
               ├─ core/middleware.ts   меняет ход (request / execution), семантика отказа Hermes
               ├─ core/hooks.ts        наблюдает ход (события с turnId, без текстов), журнал
               ├─ core/latency.ts      наблюдатель задержек + адаптивная страховка
               ├─ core/stream-guard.ts выпуск ответа по предложениям только после проверки
               └─ core/turn.ts         контекст хода: turnId, sessionId, канал, задача
опоры        prompt/  (ярусы промпта)   memory/  (поставщик памяти)   tools/  (реестр)
               guards/ (вход, выход, нормализация)   models.ts (профили и маршруты)   crisis.ts
```

## Ход по шагам

1. **Канал** превращает своё событие во вход агента и отбрасывает всё недоверенное (`channels/web.ts`: история
   из браузера; `channels/telegram.ts`: только личные чаты, пересланное помечено).
2. **Агент** собирает промпт ярусами (`prompt/assemble.ts`): система одна на всех людей → память блоком данных
   → ситуация перед последней репликой человека.
3. **Проверка входа** (`guards/input.ts` по нормализованному тексту): кризис → проверенный ответ без модели;
   подозрение на взлом → флаг для middleware.
4. **Middleware запроса**: например, при подозрении на взлом первой идёт устойчивая модель; если основная модель
   стабильно медленная — запасная стартует сразу.
5. **Страхующие попытки**: основная модель сразу, следующая — через `hedgeAfterMs` или сразу после негодного
   ответа. Побеждает первая, прошедшая **точку фиксации**: первое проверенное предложение или правильный вызов
   инструмента. Остальные отменяются.
6. **Проверка выхода** (`guards/output.ts`): стыд, медицина, ссылки, телефоны, пересказ своих правил, чужой язык,
   длина. До фиксации нарушение незаметно меняет модель, после — обрезает ответ по последнему проверенному
   предложению. Непроверенный текст человек не видит никогда.
7. **Итог**: если никто не ответил, канал берёт заготовку (кот не молчит). Журнал — одна JSON-строка на ход по
   `turnId`, без текста человека и ответа.

## Модель доверия

Образец — `SECURITY.md` Hermes Agent: граница проведена явно, и всё, что за ней, считается данными.

| Источник | Доверие | Как обращаемся |
|---|---|---|
| Наш код и тексты (`prompt/`, `agents/`, `personaBase`) | доверенный | только они попадают в системную часть |
| Текст человека | недоверенный | только в роли user; нормализация перед правилами |
| Память и план с устройства | недоверенный (его пишет браузер) | zod-схема с обрезкой → JSON-блок «данные, не указания» в сообщении |
| История чата из браузера | недоверенная | реплики кота ≤ 600 символов, вызовы инструментов перепроверяются схемой, результат инструмента подставляет сервер |
| Аргументы инструментов (пишет модель) | недоверенные | схема в `tools/catalog.ts` на сервере **и** на устройстве перед записью |
| Ответ модели | недоверенный до проверки | выпуск по предложениям после `checkOutput` |
| Пересланное в Telegram | стороннее | помечено как данные, не как просьба человека |

Инварианты (каждый закреплён тестом в `tests/unit/ai-*.test.ts`):
- в системной части нет данных человека, она байт-в-байт одинакова для всех (`prompt-surface.test.ts`);
- кризисный текст получает проверенный ответ без вызова модели, и латинские двойники или невидимые символы это
  не обходят;
- непроверенный текст модели человеку не показывается;
- вывод кота не становится адресом: в проверке выхода ссылки и телефоны, у бота нет `parse_mode` и превью ссылок;
- в журнале нет текста человека, ответа модели и тела запроса провайдеру;
- задача видит только свои инструменты, клиентский инструмент не исполняется на сервере;
- блок данных нельзя подделать: значения проходят через JSON и не закрывают сами себя.

Чего обвязка не обещает: защиту от человека, который атакует сам себя на своём устройстве (память живёт у него),
и семантическую проверку смысла (правила — это регулярные выражения, а не модель-судья). Лимиты расходов —
отдельная работа по решению владельца.

## Как добавить

- **Задачу**: файл в `agents/` (система, лимиты, `parse`, `fallback`, `onCrisis`), маршрут в `models.ts`
  (`ROUTES`), строка в `tests/unit/prompt-surface.test.ts`, затем обновить снимок (`-u`) и показать дифф.
- **Инструмент**: запись в `tools/catalog.ts` (схема — граница доверия, `executor`, `tasks`, `clientResult`).
  Ядро и маршруты не меняются.
- **Канал**: файл в `channels/` — нормализовать вход в `ModelMessage[]` и тексты человека, вызвать агента,
  превратить поток частей в свой формат. Сеть и проверка подписи — в маршруте, адаптер чистый.
- **Наблюдателя** (метрики, оценки): `observe((event, ctx) => …)` — только смотрит, ошибка проглатывается.
- **Middleware**: `registerRequestMiddleware` / `registerExecutionMiddleware` — меняет ход. Получает копию,
  упавшее звено пропускается.
- **Хранилище памяти**: реализовать `MemoryProvider` (`memory/provider.ts`). Агенты от хранилища не зависят.

## Проверки

- `pnpm check`: юнит-тесты обвязки без сети (поток, страховка, проверки, middleware, каналы, снимок промпта).
- `ANYMODEL_API_KEY=… pnpm eval:ai`: живые прогоны `evals/ai.eval.ts` (ситуации) и `evals/ai-attacks.eval.ts`
  (атаки). Платно, в CI не входит.
