# 18-01 · Квиз и персонализация — сбор применимых приёмов (09.11.2026)

Тема: ветвящиеся квизы, квиз-воронки (Noom, Simple, Liven, Lasta, Flirtist, Nebula, Sumizeit), метод «Ask» Левеска, самоубеждение,
вложенное усилие, полосы прогресса, микро-обязательства, страница результата, экраны «считаю», почта внутри квиза, граница Барнума,
формат вопросов и ответов, A/B-кейсы (Adapty, Closeable, Conversion Fanatics, GoodUI, Unbounce).

Как читать. 63 приёма. Дубли с `knowledge/techniques.md` (Q01–Q81, PL01–PL32, LP, ST, PW, DK) проверены grep'ом. Где похожий уже есть,
в строке только новое, с пометкой «дополняет XX». Все приёмы проходят красные линии product-science.md:
- ответы и балл ASRS не используются ни в персонализации, ни в оффере, ни в шеринге — всё ниже опирается только на наш блок
  «Как ты начинаешь» (4 вопроса типа + сфера + имя) и на поведение;
- почта не становится воротами к результату (DK14);
- счётчики только реальные.

Качество источников. GoodUI скрывает цифры за платным доступом: тесты названы, но эффекты не видны, поэтому сила ●.
Блоги вендоров (Adapty, Sumizeit, Interact, Closeable) — самоотчёты без n и p: ●, «проверить A/B».
Цифр по конверсии самих Noom, BetterMe, Headway, Mimika и Flo в открытом доступе нет. Есть только разборы экранов, поэтому
из этих воронок взята механика, а не числа.

- Liven: «77 % начинали с той же энергией, что и ты» — одна цифра для всех (DK48).
- Liven: график «non-customized» мелким шрифтом (PL27).
- Noom: выбор темпа не меняет дату (Q63 — выбор обязан что-то менять).

- Nebula: выход с «скрытым триалом за 1 €» (DK50).
- Simple: дата «приближается» ради эмоции (PL26).

## Топ-15 к внедрению первыми (большой ожидаемый прирост, малая цена)
1. **№39** Результат сразу ведёт в 2 минуты с котом — анкета + урок: триал +25 %, ARPU +78 %.
2. **№20** Лестница ступеней «результат → 2 мин → если — то → сохранить», без пустых «да» и без большой просьбы рано.
3. **№36** «Напарник считает» с подписями его разделов (видимая кухня: +22 % к оценке качества).
4. **№15** «Если — то»: вторую половину дописывает сам (генерация, d = 0,40).
5. **№16** Цитата его ответа из блока типа на результате (самоотнесение, d ≈ 0,5).
6. **№14** Открытый вопрос самоубеждения на результате вместо утверждения.
7. **№41** Время напоминания внутри плана (+6,4 % триал, +24 % ARPU).
8. **№42** CTA-итог: «Сдвинуть дело за 2 минуты» (+17 % триал).
9. **№23** Сохранение в два шага: канал, потом контакт (+59 %).
10. **№25** «Прислать план на 7 дней» с бейджем «План готов» вместо «Подписаться».
11. **№47** Анти-Барнум правила для 4 текстов типов.
12. **№1** Первая точка полосы залита на входе (34 % против 19 %).
