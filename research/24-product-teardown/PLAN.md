# Напарник под ключ: что внедрить и где (сводка A + B + C, 15.11)

Источники: A-adhd-apps-features.md (24 продукта, функции), B-dopamine-gamification.md (наука подкрепления, 16 продуктов),
C-breakdown-and-focus.md (дробление и Фокус). Сила доказательств — по отчётам (●●● мета / ●● исследования / ● слабые / ? нет).
Проверено мной по коду 15.11: на острове 16 находок (lib/island-elements.ts); находка «Кот» — векторный силуэт
(lib/island-sprites.tsx) — нарушает правило «одна модель кота»; на экране выбора шага Фокуса два списка шагов сразу
(чипы «Первый шаг» и блок «Выбери первый»); дробление на проде — через модель (source: model).

## Главная мысль
Персонаж + дробление + таймер в одном продукте нет ни у кого из 24 разобранных (ближе всех Focus Friend — без дробления,
goblin.tools — без персонажа). «Спрятать цифры» — тоже ни у кого. Это наше ядро; всё ниже — усиливает «начать один шаг рядом с котом».

## Навигация (нужно «да» владельца)
Фокус — действие, а не место: запускается с Дома и из «Дел», идёт на весь экран, меню прячется (Forest, Focus Friend, Opal).
Вкладка «Фокус» сейчас — второй вход в то же действие. Предложение: меню **Дом · Дела · Мир**. «Дела» — очередь шагов по
делам (куда уходят остальные шаги после дробления), рутины, вечер. Если ушёл со страницы во время сессии — над меню пилюля
«Фокус 12:40».

## Этап 1 — ядро старта (Фокус: выбор шага, сессия, финал)
1. Один шаг крупно и уже выбранный, ещё два мельче, остальные свёрнуты «ещё N»; убрать второй список (C ●●: Bandura &
   Schunk; полный список с суммой минут делает дело «длиннее» — Kruger & Evans ●●).
2. У шага: «Ещё мельче» / «Своими словами» / «Не то» (goblin, A №1).
3. Минуты только у первого шага «≈5 мин», сразу подставлять в длительность; вариант «5 минут — просто начать» (слепота ко
   времени при СДВГ, мета 55 исследований ●●●).
4. На кольце — время окончания словами «закончишь к 19:40» (Llama Life End Time — самая хвалимая функция, A №2).
5. В сессии: «Отвлёкся» (мысль в записку, таймер идёт), одна пауза без вопросов, «+5 минут», «Сделал раньше»;
   уход со вкладки — «я тут, продолжаем?» без наказания (Forest/Focus Friend наказывают — не брать).
6. Финал: награда как сейчас → «Как было?» по желанию → три пути: следующий шаг с тем же котом (цепочка, очередь уже
   хранится) / перерыв 5 минут / «на сегодня всё» + «когда следующий раз?». Звук конца. Кот называет усилие словами
   человека (похвала поднимает интерес, Deci ●●●).

## Этап 2 — Дом и «Дела»
7. Поле «Что сейчас висит?» принимает несколько дел сразу — кот берёт одно на сейчас, остальное кладёт в «Дела» (Saner,
   Tiimo Co-Planner, goblin Compiler — A №5).
8. «Не могу начать» — вторая записка на Доме: 1–2 вопроса (страшно / непонятно / нет сил / скучно) → свой тип первого шага
   (Amazing Marvin Procrastination Wizard — самая хвалимая функция Marvin, A №9).
9. Вкладка «Дела»: очередь шагов по каждому делу, прогресс — тропинка огоньков (не полоса с делениями — её отверг владелец).

## Этап 3 — Мир: новизна, которая держит месяцами (B §4)
10. Пул находок 16 → сезонные наборы + варианты одной находки («зимородок», «синица» вместо «птица») + подпись момента
    («прилетел в ноябрьский вечер») (Redden ●●). Находку «Кот» заменить (правило одной модели).
11. «За ночь на острове…» — маленькое приятное изменение утром, только если вчера был старт (Pokémon Sleep).
12. Понедельник — «Неделя острова»: что выросло за 7 дней, без сравнения (Dai fresh start ●●). Счёт «дней с котом в этом
    месяце» — не подряд, не сгорает (Lally ●●).
13. Сезон 1-го числа (небо в коридоре светлоты, свои находки), праздники РФ (1 сентября, Новый год); сезонное
    возвращается через год — без «упустил навсегда».
14. Неожиданное без обещания: «кот припас» мелочь, бутылка с запиской при возвращении (раз за возвращение).

## Этап 4 — привычки
15. Рутины = сохранённые цепочки шагов с таймерами (Routinery, Brili, Tiimo — A №7), запуск с Дома, напоминание ботом.
16. Вечер: «что сегодня сдвинулось» — только сделанное (Sunsama shutdown, Finch).
17. «Сколько сил?» в один тап — меняет длину и мелкость шага (Structured, Finch — A №8), не чаще одного вопроса за визит.

## Не делать (B §5, A)
Серии, которые сгорают; мёртвое дерево/урон/увядание; таблицы лидеров; обещание награды заранее («досиди — шанс ×3»);
«почти выпало»; редкое «только сегодня»; авто-раскладка всего дня ИИ (Motion: «забирает контроль»); блокировка приложений
(веб не может); писать в рекламе «body doubling доказан».
