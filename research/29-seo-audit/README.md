## Ждёт решения владельца (меняет экран или тексты)

1. **С лендинга нет ссылок на тест и «Помогает»** (всего 3 ссылки: знакомство, политика, условия). Для поисковика тест —
   страница-сирота. Нужна хотя бы одна текстовая ссылка с лендинга (например, рядом с юридической строкой).
2. **Лендинг — 66 слов.** Ранжироваться не за что, кроме заголовка; решается ссылками из п. 1, не текстом на первый экран.
3. **Страницы «Помогает» по ~210 слов** — тонко для поиска; расширять — работа над текстами.
4. **Заголовок лендинга без ключевых слов** («прокрастинация», «фокус», «СДВГ»). Пример: «Напарник — помощь начать
   дело при прокрастинации и СДВГ». Это текст вкладки и строка в выдаче.
5. **Подтвердить сайт в Яндекс.Вебмастере и Google Search Console** и отправить sitemap — без этого не видно ни
   индексации, ни запросов. Частотности Wordstat (research/14-lead-magnets/owner-asrs-bridge.md, «SEO»).
6. **Свой домен** (`CANONICAL_HOST`, CLAUDE.md §5.5): вес в поиске, набранный на vercel.app, при переезде переносится
   только 301/308 — они уже готовы в `next.config.ts`; адрес сайта в `lib/seo.ts` (`SITE_URL`) тогда поменять.
