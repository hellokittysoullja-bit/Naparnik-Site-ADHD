# Партия 11: учёба своими словами, дела существительным и новые дела (21.11)

Задача владельца 21.11: «Добавь новые дела, 2500, причём в разных словосочетаниях, разными способами постановки
предложения, в том числе до сих пор умной базы нет, пишу: дз по истории, сделать дз к истории, сделать дз по истории».

Три части:

1. **Учёба своими словами** — правило в поиске, не синонимы по одному (`studyRewrite` в
   `lib/ai/agents/breakdown-understand.ts`, второй заход в `understand()` в `breakdown-match.ts`).
2. **Дела существительным** — «Мытьё духовки», «Запись к стоматологу», «Звонок маме», «Покупка зимней резины» для дел
   базы и партии (`tools/forms.py`, падежи — словарь pymorphy3).
3. **Новые дела** — через goblin.tools, каждый план прочитан и поправлен вручную (`tools/cur*.py`, у правки причина в `why`).

## 1. Учёба своими словами

До: из 4284 учебных фраз (глагол × «дз / домашка / домашнее задание / домашняя работа / уроки / задание» × «по / к / для /
на» × 17 предметов, `tools/study.mts`) база узнавала 214 (5 %): «сделать дз к истории», «домашнее задание по математике»,
«решить дз по алгебре», «дз по англу», «сделать задание по истории» уходили модели.

После: 4284 из 4284. Что понимается:

- предмет в любом падеже и сленгом после «по / к / для / на»: «к истории», «для математики», «на историю», «по англу»,
  «по матеше», «по литре», «по инфе», «по общаге», «по русу», «английскому языку» → «по истории», «по английскому»…
  (`SUBJECT_FORMS`);
- словосочетания домашки: «домашнее задание», «домашнюю работу», «домашкой», «дз», «уроки» → «домашку» (`HOMEWORK_PHRASES`);
- глагол домашки: «решить», «доделать», «выполнить», «написать», «заняться» дз → «сделать»; домашка без глагола — «сделать»
  (`HOMEWORK_VERBS`);
- «задание», «упражнения» с предметом школы → домашка; без предмета «задание» может быть рабочим — не трогаем;
- предмет в начале фразы: «по истории дз».

Порядок, чтобы своё дело с предметом не терялось: фраза как написана без срезания уточнений → переписанная без срезания
(«дз по англу» → «Сделать домашку по английскому», а не общее «Сделать домашку») → как написана со срезанием → переписанная
со срезанием. Два плана на любом шаге — стоп, план пишет модель. Всё, что находилось раньше, находится так же: правило
включается, только если фраза как написана ничего не дала.

Попутно — глаголы того же смысла (`VERB_SAME`): «отремонтировать» → «починить», «приобрести» → «купить», «заменить»,
«сменить» → «поменять», «очистить», «вычистить» → «почистить», «отмыть», «перемыть» → «помыть», «прибраться» → «убраться».
«Прикупить» сознательно нет: тест 17.11 требует, чтобы «прикупить машину» шло модели.

Проверка: проверочный набор `tests/fixtures/breakdown-golden.ts`, группа `STUDY_WORDS` (живые фразы владельца и ловушки:
«сделать задание», «задание по работе», «сдать дз» — не домашка).

## 2. Дела существительным

`tools/forms.py`: глагол → существительное (Помыть → Мытьё, Записаться → Запись, Позвонить → Звонок, Поменять → Замена,
а для причёски, тарифа, пароля, врача — Смена), объект из винительного в родительный у главного слова и прилагательных перед
ним, всё после главного слова не трогается («Поиск работы мечты», «Сдача анализа крови», «Установка приложения банка»).
Защиты: слова нет в словаре — формы не делаем («кофемашину» словарь склоняет как «кофемашиной»); «Погладить кота» — не
глажка; латиница и аббревиатуры не склоняются; «цветы» → «цветов» (словарь считает их множественным от «цветок»).
Форма принимается, только если поиск по ней сейчас ничего не находит; если находит другое дело — форма выброшена.

## 3. Новые дела

Кандидаты — семьи «глагол + предмет», где план правда зависит от предмета (уборка и чистка вещей, стирка по видам, блюда,
врачи и анализы, документы, техника, ремонт, учёба по предметам, работа за компьютером, деньги, сезонные дела, люди,
дети, питомцы, машина), и отдельные дела. Отсев до гоблина (`tools/filt.mts`): дословно, понимание, опечатки, подмена
глагола по группам (Купить ↔ Выбрать ↔ Заказать, Сходить к ↔ Записаться к, Помыть ↔ Почистить…), одинаковые основы слов.
Из 4300 кандидатов база уже знала 1600 — она плотная; учебные дела с предметом («Подготовиться к контрольной по истории»)
оставлены новыми: у них свой план.

Главное, что исправлено вручную:

- **Опасное своими руками** → «проверить простое → мастер»: розетка, проводка, выключатели, плита и духовка (газ),
  вытяжка, котёл, счётчики, крыша, жёсткий диск (вскрывать нельзя), зарядка ноутбука (гоблин резал и паял кабель),
  магнитола, сигнализация, автозапуск, фаркоп, парктроники, ГРМ, свечи, замена масла и шин, мойка двигателя, тонировка
  (по закону), удаление бородавки, чистка ушей палочками.
- **Не тот смысл**: «Сдать биохимию крови» — экзамен; «Поменять прокладку» — прокладка крана (рядом «Поменять тампон»);
  «Закрыть вклад» — вкладка браузера; «Перевести себя на бюджет» — личные деньги; «Поставить автозапуск» — автозапуск
  программ; «Снять напряжение» — электричество; «Собрать пенал» — сборка из деталей; «Пополнить тройку» — не понял, что
  это транспортная карта; «Сдать курсовую» — писал курсовую с нуля.
- **Сняты**: «Перевести часы на зимнее время» (в России не переводят), «Сделать ошейник от блох» (самодельный с маслами
  опасен для котов), бессмысленные («Достать ключи из куртки», «Открыть окно на зиму», «Выучить свой номер паспорта»).
- **Форма**: повелительная форма и «вы» → неопределённая форма и «ты» (`cur0.py`); новое: «ты имеете» → «ты имеешь»,
  «хотишь» → «хочешь»; склейки генератора «Записаться к на …» → «Записаться на …», «Заказать торт на заказ» → «Заказать торт».
- **Дубли внутри партии** (`tools/indup.py`): «Пожарить чебуреки» = «Приготовить чебуреки», «Выбрать фен» = «Купить фен» и т. п.
