# Понимание дел: второй этап узнавания (20.11)

Владелец 20.11: «чтобы база больше понимала, при этом без несостыковок и багов». До этого база узнавала дело, только если человек написал
его так же, как оно названо (с точностью до регистра, порядка слов, слов-паразитов и опечаток). «Покормить собаку вечером», «мыть посуду»,
«накормить пса», «написать курсовую по истории» уходили модели: 3 секунды, деньги, нужна сеть, а при пустом балансе ключей плана не было вовсе.

## Как устроено

`lib/ai/agents/breakdown-understand.ts` (данные) + `understand()` в `lib/ai/agents/breakdown-match.ts` (поиск). Порядок поиска:

1. **дословно** — как раньше;
2. **понимание** — закрытые списки, без догадок:
   - уточнения времени: «вечером», «после ужина», «в субботу», «в 19:00», «до пятницы» (`TIME_DETAILS`, время числом);
   - предмет учёбы «по истории» — только у учебных дел (`STUDY_HEADS`) и только для предметов из списка (`SUBJECTS`): «экзамен по
     вождению» и «доклад по работе» не трогаются;
   - вид глагола: «мыть» → «помыть», «кормить» → «покормить» (`ASPECT`, только пары с тем же смыслом: «пить», «есть», «учиться» нет);
   - другой глагол того же смысла: «накормить» → «покормить», «вымыть» → «помыть» (`VERB_SAME`);
   - формы: «помыла», «покорми», «помою» → «помыть» и т. п. (`VERB_RULES`: кандидат принимается, только если такой глагол есть в
     названиях дел, и только если он один);
   - другое слово для предмета: «пса» → «собаку», «курсач» → «курсовую» (`NOUN_SAME`, только однозначные и без рода: «кошку» → «кота»
     нет — «кастрировать кошку» ушло бы в план про кота, а у кошки своё дело; «тачку» → «машину» нет — на даче тачка садовая);
3. **опечатки** — как раньше, но ПОСЛЕ понимания: раньше настоящее слово, которого нет в базе, «исправлялось» в похожее чужое
   («мыться» → «Умыться»).

Правила принятия:
- остаток после правок должен **дословно** совпасть с делом или синонимом базы (опечатки в понимании не правятся);
- уточнения убираются по одному, начиная с наименьшего числа: «убраться на кухне вечером» → «Убраться на кухне», а не «Убраться»;
- слово, написанное как есть, сильнее замены: «готовиться к экзамену» — своё дело, хотя замена дала бы «Подготовиться к экзамену»;
- два разных плана на одном шаге → не угадываем, план пишет модель («отдохнуть в выходные вечером»: и «Отдохнуть в выходные», и
  «Отдохнуть вечером»);
- название дела — дело базы плюс уточнения человека: «Покормить собаку вечером», «Написать курсовую по истории», «Позвонить маме в 19:00».

## Проверка

| Проверка | Результат |
|---|---|
| Проверочный набор `tests/fixtures/breakdown-golden.ts`, 245 фраз (живые формулировки, ловушки, уже узнававшееся) | без понимания 126 из 219, с ним 219 из 219; чужих планов 0 |
| Каждое из 3 219 дел + время спереди и сзади (32 290 фраз, `tools/inv.mts`) | 32 282 своё дело, 6 — более узкое дело с этим временем («Поесть вечером»), 2 не узнались (двусмысленно) |
| Каждое дело с глаголом в другом виде и форме (13 327 фраз, `tools/inv2.mts`) | 13 316 своё дело, 8 не узнались, 3 — дела, которые ровно так названы («Вставать рано» рядом с «Встать рано») |
| Поиск без понимания и с ним на каждом 40-м деле и его опечатках (18 270 фраз, `tools/diff.mts`) | 21 новое узнавание, все верные («варить кашу» → «Сварить кашу»); потерь 0; 3,2 мс на фразу, как раньше |
| Нарочные ошибки в правилах (неверный вид глагола, синоним, лишнее уточнение, лишний предмет, «кошку → кота», угадывание при двух планах, без приоритета слова как есть) | все 7 ловятся тестами |

Что найдено и исправлено по ходу:
- «мыться» → «Умыться»: опечатки шли раньше понимания (теперь после);
- «сдать экзамен по вождению» стал бы «Сдать экзамен»: «по <любое слово>» → только предметы из списка;
- «готовиться к экзамену вечером» не узнавалось: замена давала второе дело — слово как есть теперь сильнее замены;
- «кастрировать кошку» → план про кота, «тачку» → машина: оба синонима убраны;
- попутно в партии 8 нашлись 20 потерянных ручных дел (отдельный коммит в #144).

## Что не делает (сознательно)

- не понимает фразы, которых нет ни в одном деле: «а то псина опять скулит» — модель;
- не трактует глагол сам по себе: «взять» ничего не значит, пока вся фраза не совпала с делом;
- место («на кухне»), длительность («за 10 минут»), «на неделю» — не уточнения: от них дело меняется.
