# Компилятор: «вывали всё, что в голове» → список дел, без модели (22.11)

Задача владельца 22.11: «проанализируй компилятор в Goblin Tools, я хочу его тоже… через них научить свой продукт… без
обращения к модели. Как ты сделаешь, чтобы было как у них идеально».

## Как устроен Compiler у goblin.tools

- Страница goblin.tools/Compiler: поле «Enter your braindump here…», кнопка, список дел, кнопка «Send result to the Magic
  Todo» (перенос в их список дел). Описание: «takes a text and tries to distill a list of actionable items from it. You can
  ramble about anything and it will try its best to turn it into todo items».
- Под капотом — модель: `POST /api/Compiler?l=ru`, тело `{"Text": "…"}`, ответ — массив строк. Настроек (остроты,
  длины) нет.
- Что модель делает (по 40 нашим потокам, `goblin-compiler-raw.json`): режет на дела; выбрасывает разговорное («блин»,
  «надо», «не забыть», «хоть когда-нибудь»); ставит глагол вперёд («отчёт доделать» → «Доделать отчёт»); из жалобы делает
  действие («штраф пришёл» → «Оплатить штраф», «посуда со вчера стоит» → «Помыть посуду»); раскрывает местоимения («купить
  ему кроссовки» → «купить ребёнку кроссовки»); оставляет сроки («к пятнице», «в субботу»); чувства без дела
  выбрасывает («мне плохо, ничего не хочу» → только «помыться», «поесть»). Слабые места: голые слова остаются словами
  («уборка | стирка | поход в магазин»), на жалобу без дела («ничего не успеваю, работа, учёба, дом, всё горит»)
  выдумывает расплывчатые дела («успевать выполнять работу», «решать проблемы и избегать кризисных ситуаций»), регистр
  букв скачет.

## Как сделано у нас (`lib/ai/agents/compile.ts`, `/api/compile`)

Те же шаги, но правилами и базой дел, без модели, мгновенно и бесплатно:

1. **Режем** на фразы по знакам, переносам и связкам («ещё», «потом», «а также», «плюс», «а я …»). «И» режет, только
   если справа новое дело с глаголом: «позвонить маме и папе» — одно дело, «помыть кота и его покормить» — два.
2. **Счищаем разговорное** по краям и внутри («блин», «короче», «надо бы», «хочу», «не забыть», «наконец», «какие-то»,
   «этот дурацкий»), причины и оговорки («а то места нет», «если не заплачу»). Сроки остаются («к пятнице», «на завтра»,
   «в субботу»).
3. **Глагол вперёд**, форма → неопределённая («отчёт доделать» → «Доделать отчёт», «помою» → «помыть») по словарю форм
   базы (`breakdown-verb-forms.ts`). Если перед глаголом чужое действие («мама просила помочь…») — оно отбрасывается.
4. **«Не сделал» → сделать**: «подарок не купил» → «Купить подарок», «диплом не пишу» → «Писать диплом».
5. **Жалоба → действие**: «X кончился» → «Купить X», «X пришёл / не оплачен / отключат» → «Оплатить X» (с падежом:
   «квартплата» → «квартплату»), «X сломался» → «Починить X».
6. **Фраза без глагола — к базе дел** (7554 дела и синонимы): «посуда со вчера стоит» → «Помыть посуду», «зал» →
   «Сходить в спортзал», «экзамен по истории» → «Подготовиться к экзамену по истории»; «к стоматологу», «в деканат» →
   «Сходить …».
7. **Местоимения** — тот, о ком шла речь: словарь людей и животных с падежами (ребёнок, сын, мама, бабушка, кот…) и
   вещь из прошлого дела («продать старый велик…, сфоткать его» → «Сфоткать старый велик»).
8. **Списки**: «надо купить: хлеб, сыр, колбасу» → «Купить хлеб, сыр, колбасу»; «купить продукты, молоко хлеб яйца» →
   «Купить продукты (молоко, хлеб, яйца)»; «разобрать шкаф…, и балкон тоже» → «Разобрать балкон».
9. **Не дела** — чувства, рассказ о других, общие слова: «мне плохо», «он ждёт уже неделю», «зуб болит», «всё горит».
   Своё слово, которого база не знает («Хрюндель»), не теряется — остаётся делом как есть.
10. Названия с большой буквы: МФЦ, Озон, Авито, Питер, ИКЕА.

На экране — то же поле «Вывали всё, что в голове» в «Делах»: пока человек пишет, сервер через 0,35 с отвечает списком, и
кнопка показывает «Положить N дел» по нему; нет сети или сервер не ответил — прежнее деление по запятым (`splitDump`).

## Сравнение на 40 потоках (`dumps.txt`, построчно — `side-by-side.txt`, счёт — `score.mts`)

| | |
|---|---|
| потоков | 40 |
| список дел совпал дословно (без учёта регистра) | 22 |
| столько же дел, сколько у goblin.tools | 35 |
| дел у goblin.tools | 118 |
| из них у нас слово в слово | 90 (76 %) |

Расхождения по сути (остальные — синонимы: «Сходить к стоматологу» / «Обратиться к стоматологу», «Написать курсовую» /
«Сделать курсовую работу»):

- лучше у нас: «уборка, стирка, магазин» → действия («Убраться в комнате», «Постирать бельё», «Сходить в магазин»), а не
  голые слова; на «всё горит, ничего не успеваю» — ни одного выдуманного дела;
- лучше у goblin.tools: «научник пишет, а я молчу» → «Обсудить диплом с научным руководителем» (понимает смысл
  ситуации — правилами это не сделать); «подарок не купил» после «у Лены день рождения» → «Купить подарок Лене на день
  рождения» (связывает фразы); «Написать начальнику о задержке» вместо «…что задержусь»; «Лабораторную работу» вместо
  «лабу».

## Что дальше (по желанию владельца)

- Кнопка «Вывалить» на Доме и в боте (бот: длинное сообщение с несколькими делами → список «положить в Дела?»).
- Связки между фразами («у Лены день рождения… подарок не купил» → «Купить подарок Лене»): правило «у X событие» +
  следующее дело с подарком/поздравлением.
- Новые жалобы и «люди» в словари — по мере того, как владелец увидит живые потоки.
