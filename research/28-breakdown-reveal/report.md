# 28. Как лучшие продукты показывают «обрабатываю» и «вот план»: разбор и концепции для разбивки дела (16.11)

Задача владельца: разбивка теперь мгновенная (база 554 дел), нужна НАМЕРЕННАЯ «иллюзия работы» ~1–1,5 с — красивая,
оригинальная анимация «дело дробится», плюс приёмы восхищения и подача первого шага. Goblin Tools не рассматривался.

Связанные ID базы: PL01 (честная иллюзия работы), PL02 (превращения, не эхо), PL03 («собираю» ≤ 1 с или без него),
PL04 (без фальшивых процентов). Этот отчёт их не отменяет — уточняет для экрана разбивки.

**Честность метода.** Научная часть — по первоисточникам (Buell & Norton 2011 прочитан целиком, цифры оттуда).
Покадровые описания продуктов — по публичным описаниям, обзорам и знанию интерфейсов; длительности помечены «≈» и
НЕ замерены записью экрана в этом сеансе. Перед внедрением конкретного образца — снять его на видео.

## 1. Наука: что известно про ожидание, иллюзию работы и раскрытие

| Факт | Цифры | Источник |
|---|---|---|
| Иллюзия работы: видимый процесс повышает ценность при ОДИНАКОВОМ результате | Ценность 5,36 против 4,96 (из 7) с прозрачностью vs без; выше на каждой длительности 10–60 с | Buell & Norton 2011, эксп. 1 |
| Видимая работа побеждает мгновенный ответ | Выбрали сайт с ожиданием 30 с и списком «что ищу» — 62 %, 60 с — 63 %; то же ожидание вслепую — 42 % и 23 % | там же, эксп. 2 |
| Работает «ощущение усилия», а не объём работы | 3 сайта против 36: на ценность объём не влиял, влияла прозрачность; механизм — усилие → взаимность («он постарался для меня») → ценность | там же, эксп. 3–4 |
| **Граница 1: плохой результат** | Видимая работа + плохой итог = ХУДШАЯ оценка из всех условий (хуже, чем вслепую) | там же, эксп. 5 |
| **Граница 2: ожидание по меркам жанра** | Польза начинала падать после 30 с (авиабилеты) и уже после 15 с (знакомства — привыкли к быстрому); «Google приучил к долям секунды» | там же, обсуждение |
| Прозрачность «повара ↔ гости» | Оценка качества +22,2 %, время обслуживания −19,2 % | Buell, Kim, Tsay 2017 |
| **Против: медленный алгоритм теряет доверие** | 7 исследований, N = 1928: медленные прогнозы алгоритма считали менее точными, медленные прогнозы человека — более точными. Причина: «для машины задача лёгкая, усилие не значит качество» | Efendić, Van de Calseyde, Evans 2020 |
| Задержка «по-человечески» | Чат-бот с динамической задержкой (по сложности ответа) — выше человечность, присутствие, удовлетворённость; но у опытных пользователей эффект обратный | Gnewuch et al. 2018; 2022 (N = 202) |
| Ускоряющийся прогресс кажется быстрее | Полоса «медленно в начале → быстро в конце» воспринимается короче той же длительности | Harrison et al. 2007 (UIST) |
| Пороги отклика | 0,1 с — мгновенно; 1 с — поток мысли не рвётся; 10 с — внимание уходит | Nielsen, «Response Times: 3 limits» |
| Занятое ожидание короче пустого; необъяснённое — длиннее | Качественные законы очередей | Maister 1985 |
| «Собираю план» — редкость | 9 из ~751 приложений с квизом | Lazyweb 2026 (уже в PL01) |
| Цель ближе — усилие растёт; «подаренный» прогресс | Карта 12 штампов с 2 подаренными заполняется быстрее карты на 10; автомойка: 34 % против 19 % | Kivetz et al. 2006; Nunes & Drèze 2006 |
| Предвкушение | Дофамин отвечает на сигнал, предсказывающий награду; максимум — при неопределённости ~50 % | Schultz 1997; Fiorillo et al. 2003 |
| СДВГ: неприятие задержки | Ожидание без дела субъективно тяжелее, чем у нормотипичных | Sonuga-Barke 2002 (delay aversion) |

**Выводы для «Напарника»:**
1. Иллюзия работает через **«он постарался для меня»** (взаимность) — у нас это кот, то есть «человеческий» исполнитель:
   по Efendić медленный КОТ (персонаж с усилием) в выигрыше, медленная «машина» — в проигрыше. Поэтому усилие должно
   быть ЖЕСТОМ кота/огонька, а не крутилкой или «AI обрабатывает».
2. Жанр задаёт потолок: от кнопки «Разломать» люди ждут мгновенности (как поиск, не как билеты). 1–1,5 с — уже у
   границы «потока мысли» Нильсена. **Потолок 1,5 с, для вернувшихся — 0,6–0,9 с.** Для СДВГ (delay aversion) каждые
   100 мс пустоты дороже — пустых кадров не должно быть вовсе: каждый кадр что-то происходит с ЕГО словами.
3. Прозрачность конкретна: Buell показывал список АВИАКОМПАНИЙ, которые ищет сайт, — не «Загрузка». Наш аналог —
   слова человека на экране и видимые «части» дела.
4. Граница 1 опасна для нас: если после красивой ломки план плохой/общий («Не понял дело», заготовка) — хуже, чем без
   анимации. **Анимация только при уверенном плане** (из базы или модели); для `unclear` и ошибок — сразу ответ кота,
   без театра.

**Общие закономерности сильных примеров:**
1. Работу делает **персонаж или физический объект**, а не полоса (Stardew, Duolingo, Motion).
2. **Твои слова видны в процессе** и становятся каркасом результата (Granola, Perplexity, Headway).
3. Есть **предсказывающий сигнал** перед раскрытием (свечение редкости, трещина).
4. **Квитанция усилия после** («Думал 12 с», «Прочитал 6 сайтов»).
5. **Пропуск/укорочение** для повторов (Hearthstone массово, Duolingo тап).
6. Первый элемент результата **сразу выделен** и ведёт к действию (Brilliant).

## 3. Семь концепций для «Напарника»

Общие правила для всех концепций (из §1 и CLAUDE.md):
- кот — только существующая кукла `MascotDoll` (позы: `think`, `celebrate`, `wave`, касание-присед, огонёк на хвосте);
- двигаем только `transform`/`opacity`; без `filter: blur`, масок и `backdrop-filter` на крупных элементах; частицы —
  мелкие DOM-элементы (≤ 12) или один `<canvas>` 2D небольшого размера;
- текст дела — реальный текст в DOM (доступность), анимируем обёртки слов/букв;
- **длительность по стажу**: 1–3-я разбивка ≈ 1,3 с; 4–10-я ≈ 0,9 с; далее ≈ 0,6 с (только жест + раскрытие);
  тап по экрану — сразу финал; `prefers-reduced-motion` — без ломки, план сразу с репликой кота;
- **анимация только при уверенном плане**; `unclear`/ошибка — сразу реплика кота (граница Buell эксп. 5);
- хаптика — одна, `hapticReward` на моменте «раскола» (событие мира, §4 CLAUDE.md), не на каждый осколок.

### К1. «Полено» — кот колет дело, щепки становятся шагами ★ рекомендую
Метафора костра уже есть на Доме: дело — полено, шаги — поленья поменьше, которые можно подкинуть в огонь.
| мс | Кадр |
|---|---|
| 0–150 | Текст дела человека (его слова) «сжимается» в плашку-полено (тёплая коричневая заливка, волокна — 2 линии), строка «Секунду, разламываю…» не нужна |
| 150–450 | Кот `think` → касание-присед (ход назад), огонёк на хвосте вспыхивает (scale 1→1,3) — «замах» |
| 450–600 | Удар: кот «прыгает» (celebrate-подскок), по полену пробегает трещина (SVG-path `stroke-dashoffset`), хаптика |
| 600–900 | Полено раскалывается на N щепок (N = число шагов!), щепки подлетают на 20–40 px и раскручиваются, на каждой — 1–2 слова будущего шага |
| 900–1300 | Щепки встают в столбик и «распрямляются» в строки шагов; первая крупнее, подъезжает к карточке «первый шаг». Остальные тускнеют до 60 % |
Приёмы: LI (жест кота = усилие), OT (видно, что ЕГО дело делится и на сколько частей), PR (его слова на полене),
AN (замах), PE (раскол — пик). Число щепок = число шагов — честная информация, не декор.
Риски: на 10-й раз — сокращать до «удар → раскол» 0,6 с; вариативность — направление разлёта и вращение случайны,
иногда (1 из 6) из полена вылетает искра-«находка» (связать с островом). Сложность: средняя (DOM + SVG, 1–2 дня).

### К2. «Огонёк прожигает швы» — хвост кота проводит линии разреза
| мс | Кадр |
|---|---|
| 0–200 | Строка дела человека ложится на «бумагу»/дощечку под котом |
| 200–800 | Светящаяся точка (огонёк — отдельный маленький DOM-круг, а не хвост куклы) пробегает по строке слева направо и оставляет тонкие тлеющие «швы» между будущими шагами; слова по краям шва слегка темнеют |
| 800–1100 | Куски расходятся по швам вниз лесенкой (stagger 60 мс) и превращаются в строки шагов |
| 1100–1300 | Первый кусок вспыхивает тёплым ободком (box-shadow фиксированный, не анимируемый — анимируем opacity обёртки) |
Приёмы: OT (точно видно, ГДЕ режется дело), PR. Изящно и «умно», меньше физики.
Риски: шаги из базы — НЕ подстроки исходного текста; швы будут условными. Решение: огонёк режет на N равных частей,
куски «переписываются» в шаги (короткий morph текста — cross-fade). Сложность: средняя.

### К3. «Искры из костра» — дело в огонь, шаги вылетают искрами
| мс | Кадр |
|---|---|
| 0–300 | Строка дела «улетает» дугой в костёр (Дом, `campfire.tsx`) |
| 300–600 | Пламя вспыхивает (scale/opacity уже существующих языков), кот поворачивает голову к огню (взгляд куклы) |
| 600–1100 | Из огня вылетают N искр, гаснут в воздухе и на их месте проступают строки шагов (сверху вниз) |
| 1100–1400 | Первая искра не гаснет — становится огоньком у первой строки («горит» = сейчас) |
Приёмы: AN, PE, диегетика (костёр отвечает на событие — §3 «контингентность»). Красиво именно на Доме «Привал».
Риски: «сжечь дело» может читаться как «уничтожить», а Фокус открывается отдельным экраном (костра там нет — только фон
`AppBackdrop` с очагом). Работает, если разбивка показывается на Доме. Сложность: средняя-высокая (переход между экранами).

### К4. «Камень-жеода» — трещина с подсветкой, внутри шаги
Прямой перенос лучшего игрового ритуала (Stardew + Hearthstone).
| мс | Кадр |
|---|---|
| 0–200 | Дело — гладкий тёмный камень с его словами |
| 200–700 | Кот касается лапой (присед) — 2 удара: трещина растёт в 2 стадии (Minecraft), из трещин пробивается тёплый свет |
| 700–900 | Камень раскрывается половинками, внутри — светящиеся кристаллы-шаги |
| 900–1300 | Кристаллы выстраиваются в список; первый — самый яркий |
Приёмы: AN (свет в трещине — предсказывающий сигнал), VR (цвет света может зависеть от сферы/времени суток), PE.
Риски: «камень» = тяжесть, ассоциация с трудным делом — зато раскрывается легко (катарсис). Меньше связи с миром
Напарника, чем полено/костёр. Сложность: средняя.

### К5. «Кот разматывает клубок» — дело как запутанный клубок нитей
Метафора «запутался в деле» точна для СДВГ.
| мс | Кадр |
|---|---|
| 0–300 | Слова дела сворачиваются в клубок (буквы по кругу — transform по траектории) |
| 300–900 | Кот дёргает лапой, нить тянется вправо, клубок крутится и уменьшается; на нити — узелки = шаги |
| 900–1300 | Нить ложится зигзагом вниз, узелки становятся строками; первый узелок — у карточки «первый шаг» |
Приёмы: OT, IK слабый, мощная метафора «распутали». Риски: сложнее всего сделать красиво (траектория нити — SVG path
с `stroke-dashoffset`, OK), у куклы нет лапы для «дёргания» — только присед/подскок. Сложность: высокая.

### К6. «Остров даёт тропу» — шаги как камни-ступени к цели
| мс | Кадр |
|---|---|
| 0–300 | Слова дела «улетают» вдаль и становятся флажком на горизонте (связь с грядой ориентиров) |
| 300–1000 | От кота к флажку по одной выкладываются плоские камни-ступени (N шагов, stagger ~100 мс), каждый с коротким словом |
| 1000–1300 | Кот «прыгает» на первый камень (подскок + сдвиг), первый камень подсвечен — «Начать» |
Приёмы: GG (видно расстояние и первый шаг как уже «ступенька»), OT, связь с островом/Миром. Пик — прыжок кота.
Риски: план на 8 шагов — длинная тропа, нужна перспектива (камни мельче вдали — это и есть визуальная
goal-gradient иерархия). Сложность: средняя-высокая.

### К7 (вспомогательная, не самостоятельная). «Квитанция кота» вместо процента
После любой концепции — одна строка-квитанция голосом кота, вариативная: «Разломал на 4 — первый совсем мелкий»,
«Восемь кусков, но тебе нужен только первый». Аналог «Thought for 12s» (усилие задним числом) + снятие тревоги от
длины списка. Тексты — согласовать с владельцем (правило голоса кота).

### Сводная оценка
| Концепция | Связь с миром | Сила пика | Честность (OT) | Устойчивость к повтору | Сложность |
|---|---|---|---|---|---|
| К1 Полено | высокая (костёр, Привал) | высокая | высокая (N щепок = N шагов) | хорошая при укорочении | средняя |
| К6 Тропа | высокая (остров) | средняя-высокая | высокая | хорошая | средняя-высокая |
| К4 Жеода | средняя | высокая | средняя | отличная (VR цвета) | средняя |
| К2 Огонёк-швы | высокая (огонёк кота) | средняя | высокая | хорошая | средняя |
| К3 Искры | очень высокая на Доме | высокая | средняя | средняя | средняя-высокая |
| К5 Клубок | средняя | средняя | высокая | средняя | высокая |

**Вариативность против привыкания (для всех):** (1) укорочение по стажу (1,3 → 0,9 → 0,6 с); (2) случайное
направление/вращение осколков; (3) редкая находка 1 из ~6 (искра → остров, связь с VR и Миром); (4) реплика-квитанция
из пула; (5) тап = пропуск. Не варьировать сам жест — ритуал должен узнаваться (Stardew: одна и та же сцена).

## 4. После раскрытия: как подать первый шаг, чтобы захотелось нажать «Начать»

| Приём | Как у нас | Основание |
|---|---|---|
| **Один крупный, остальные тише** | Первый шаг — карточка, остальные — 60 % непрозрачности, свёрнуты после 3-го («+ ещё 4») | Brilliant; закон Хика; снижает перегруз |
| **Минуты на шаге, первый — самый короткий** | «≈ 2 мин» бейджем; если первый шаг > 5 мин — кот предлагает «Ещё мельче» | Kivetz goal-gradient; правило 2 минут; в базе минуты уже есть |
| **Подаренный прогресс — честный** | Полоска плана уже заполнена на 1 деление: «Разломать — сделано» (сам факт разбивки = шаг 0). Не процент, а деления | Nunes & Drèze 2006 (EP); PL04 — без фальшивых процентов |
| **Слова человека в заголовке** | «первый шаг · курсовая» (уже есть `dealTitle`) — сохранить, это PR | Granola, Buell OT |
| **Кнопка «Начать» — к пальцу, сразу живая** | Кнопка появляется вместе с первым шагом (не после списка), внизу у большого пальца, `.btn-wake`-подъём | Fitts; Duolingo |
| **Кот смотрит на первый шаг** | Взгляд куклы на карточку (у `MascotDoll` есть взгляд за целью) — социальное внимание направляет взгляд человека | gaze cueing (Friesen & Kingstone 1998) |
| **«Можно криво» под кнопкой** | Одна строка снятия перфекционизма (тон продукта) | ACT/снижение порога; уже в тоне Дома |
| **Пик-конец** | Пик — раскол; конец — первая строка и тёплая реплика, а не длинный список | Kahneman, peak-end |
| **Реальная редкость** | Иногда (не всегда) огонёк у первой строки «горит» ярче — «хороший шаг для старта» | VR, но только если правда (например, шаг ≤ 2 мин) |
| **Не делать** | Таймер обратного отсчёта «начни за 10 с», проценты готовности, конфетти до действия (награда до дела обесценивает пик старта), toast | PL04, §3 CLAUDE.md |

---

## 5. Рекомендация

1. Сделать **К1 «Полено»** как основу (самая сильная связь с костром Привала, честный счёт шагов, понятный пик) +
   **К7 «квитанция»**; К6 «Тропа» — кандидат на финал первой сессии/Мир, а не на разбивку.
2. Длительность — **1,3 с первые 3 раза, 0,9 с до 10-го, затем 0,6 с**; тап — пропуск; без анимации при `unclear`.
3. A/B (если появится трафик): К1 vs текущее «кот думает + строка» по доле нажавших «Начать» в первые 30 с.
4. Перед реализацией — снять видео Stardew (жеода), Duolingo (конец урока), Perplexity (шаги) и разметить по кадрам.
